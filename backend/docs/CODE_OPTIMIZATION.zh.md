# CVAgent 代码优化与审查记录

## 1. 目标

在保留产品核心行为的前提下，主动清理迁移遗留、重复实现和模块耦合，使项目适合继续开发 Agent、模板和简历排版能力。对明确的错误、无调用方代码和脱钩残留，本轮直接修正或删除，不以“低风险”为理由保留冗余结构。

本轮优化的优先级是：

1. 先保证现有行为可重复验证；
2. 收敛渲染、工作区和模板的唯一实现；
3. 清理没有进入主链路的旧代码；
4. 拆分过大的服务端和前端模块；
5. 补齐并发、异常、输入边界和文档验证。

## 2. 当前基线

- 运行时：Node.js ESM，要求 Node.js 22 或更高版本。
- Agent：`deepagents`，模型适配使用 `@langchain/openai`。
- 核心闭环：工作区 → 草稿 → 模板/排版 → 渲染 → 浏览器测量 → 验收 → 用户确认保存。
- 主要规模：`src` 约 5,000 行 JS，`public/app.js` 约 600 行，迁移渲染器和图标目录规模较大。
- 已有验证：语法检查、核心状态测试、HTTP 接口测试、日志测试和 UI 合同测试。
- 当前基线风险：服务端和前端仍偏集中；Session 已持久化到本地，但尚未引入登录和跨进程会话协调。

## 3. 优化范围

### 3.1 本轮包含

- 统一当前产品实际使用的渲染入口；
- 明确并收敛 `core` 与 `migrated/resume-engine` 的边界；
- 清理或隔离当前主链路未引用的旧版本、自动调优和旧渲染代码；
- 统一文件写入和路径校验策略；
- 抽取服务端公共 HTTP/错误处理能力；
- 修复测试清理竞态，补充关键异常和边界测试；
- 更新当前状态文档，避免历史复盘与实现不一致。

### 3.2 本轮不包含

- 不更换 Deep Agents、LangGraph 或模型供应商；
- 不重新设计 UI，不改变现有简历模板的视觉意图；本轮会清理旧样式命名和未使用选择器。
- 不引入数据库、登录系统或云部署；
- 不删除仍被当前运行时、测试或模板工作坊使用的能力；
- 不修改原 `dsh-campus-job` 项目。

## 4. 发现的问题与优先级

### 已关闭的 P0：影响正确性或后续扩展

- 旧 `renderPreview*` 链已删除，正式预览统一经过 `src/core/render.js`。
- 迁移文件适配器已统一复用 `core/workspace.js` 的原子写入；图片也经过工作区边界和扩展名/大小校验。
- Agent、手动域操作、测量和保存已通过 session lock 在单进程内串行化，避免 `taskRef` 状态回退。

### P1：明显增加维护成本

- `src/server.js` 同时处理路由、会话、任务状态、Agent 调用、渲染和版本保存。
- `public/app.js` 同时处理全局状态、视图切换、API 请求、预览测量、模板库和版本管理。
- 渲染器内嵌 CSS、模板 CSS、`styles.css` 和 `workbench.css` 同时影响同一套视觉结果；当前已移除明显无调用方的旧布局选择器，但前端样式仍可继续拆分。
- 历史 `resume-versions.js`、`autotune.js` 和旧渲染入口已确认没有当前主链路引用，已从运行时代码删除并在迁移矩阵中保留来源说明。

### P2：可读性和工程卫生

- `server.js` 中存在重复导入、重复错误码集合和重复的会话初始化逻辑。
- Agent 工具使用 Zod schema，直接 HTTP 域操作缺少统一的请求 schema，存在契约漂移风险。
- 文档包含已经过时的“尚未实现”描述。
- 旧 `dsh-*` 类名、旧资源路径、旧指标回传和兼容命名已改为 CVAgent 命名空间；文档中的历史说明仍明确标注为来源，不参与运行时。

## 6. 验收标准

- 当用户通过工作区、Agent 或手动编辑进入预览时，系统应使用同一个渲染入口和同一套模板解析规则。
- 当文件写入成功时，正式源文件应保持不变，草稿和版本写入应保持原子性。
- 当 Agent、测量和保存请求并发到达同一会话时，单进程服务应按 session lock 顺序处理，不得产生状态回退；跨进程仍需持久化会话或外部协调器。
- 当测试执行多次或串行执行时，临时目录应能稳定清理，不得依赖后台日志写入时序。
- 当模块被判定为未使用时，代码库中应没有当前运行时或测试对它的引用，或者它必须被放入明确的兼容目录。
- `npm test`、JS 语法检查和 `npm audit --omit=dev --audit-level=moderate` 应通过。
- README 和审查文档不得再把已经落地的素材读取、渲染、测量或 UI 能力描述为“尚未实现”。
- 图片资源只能读取授权工作区内的支持格式，不能穿越路径或读取 `.cvagent` 元数据。

## 7. 审查输出

最终审查需要记录：

- 变更前后测试结果；
- 删除、移动或保留的迁移模块及原因；
- 仍存在的生产化风险；
- 未在本轮处理的事项：前端 `app.js` 仍可按状态/API/视图继续拆分；服务端仍是单文件路由；Session 尚未鉴权；浏览器测量仍由客户端 iframe 回传；跨进程并发尚未协调；UI 尚未完整展示工具事件和阻断原因。
- 建议的下一阶段：MCP 工序一致性回放、真实 Agent 端到端测试、流式 Agent 和工具事件展示；单用户阶段暂不引入多用户鉴权和外部会话数据库。
