# 工作区选择产品需求

## 目标

让用户通过选择本地工作区完成 CVAgent 初始化，不再填写绝对路径或简历相对路径。

## 必须满足

1. 用户可以选择一个目录并导入到 CVAgent。
2. 系统自动识别可用的 Markdown 简历源文件。
3. UI 只持有 `workspaceId` 和展示元数据，不展示服务端绝对路径。
4. 选择完成后可以进入现有简历制作工序：读取、模板、草稿、渲染、测量、验收、保存版本。
5. 会话和版本能在刷新或服务重启后继续使用。
6. 旧的路径 API 继续兼容，避免破坏已有测试和本地迁移。

## 非目标

- 本轮不实现浏览器对原目录的直接回写；
- 本轮不改变 MCP 对齐的简历制作工序；
- 本轮不改变模板渲染器和验收状态机。
