# DSH 像素级复刻需求

## 目标

CVAgent 是独立运行的简历 Agent 产品，但其简历工作台必须复用 DSH 求职简历插件的已验证交互和视觉表现。用户在相同 Edge、窗口尺寸、缩放比例和内容状态下，不应感知到两套工作台之间的像素级差异；唯一产品差异是 CVAgent 提供独立的 Agent 模块。

## 用户故事

- 作为使用过 DSH 的用户，我可以在 CVAgent 中用同样的导航、顶部操作和双栏预览完成简历工作，不需要重新学习。
- 作为简历用户，我可以在 Agent、工作区、预览、版本、模板和排版检查之间切换，当前状态不会因为视图切换而丢失或回退。
- 作为验收者，我可以看到每个按钮对应的后端结果、渲染结果和失败原因，而不是只看到视觉上的成功提示。
- 作为维护者，我可以用固定状态截图和自动化接口测试发现 CVAgent 与 DSH 的视觉或行为回归。

## 范围

必须完成：

1. DSH 工作台可见 DOM 层级、CSS 令牌、字体、间距、控件状态和响应式行为复用。
2. 工作区读取、模板选择、模板工坊、Markdown 草稿、实时渲染、排版调整、图标微调、版本保存/另存为/改名/归档、HTML/PDF 导出和排版检查全部连接 CVAgent 后端。
3. Agent 视图独立存在，调用同一套领域工具，并在内容、渲染、测量、验收、保存之间保持任务关联。
4. 每个核心状态具备浏览器截图基准和后端验证。

明确不做：

- 不把 DSH 宿主的会话列表、模型选择器或宿主侧导航复制进独立产品。
- 不重新设计 DSH 已有工作台的颜色、字体、布局和交互文案。
- 不以静态假数据或仅更新状态文字代替后端操作。

## EARS 验收标准

- 当用户进入预览视图时，CVAgent 应只显示左侧工作台导航、主区顶部操作栏和 Markdown/A4 双栏，不显示工作区输入条、其他视图内容或重复操作栏。
- 当用户切换到工作区、模板库、模板工坊、投递版本或排版检查时，预览双栏应隐藏，目标视图应独占主区。
- 当用户点击读取、应用模板、保存草稿、应用排版、运行检查、保存版本或另存为时，系统应调用对应后端接口，并在返回前显示处理中状态，失败时保留当前草稿和明确错误。
- 当用户切换模板或打开投递版本时，系统应恢复该实体绑定的 Markdown、模板 ID、模板修订和排版参数，不得回退到默认值。
- 当用户编辑 Markdown 时，系统应只更新隔离草稿和当前渲染，不得静默修改源文件或切换工作区。
- 当用户打开 Agent 时，Agent 应显示当前工作区、简历、模板和任务状态，并可驱动读取、改稿、渲染、测量、验收和保存流程。
- 当页面处于相同浏览器基准状态时，CVAgent 与 DSH 截图的结构差异应为零；允许的差异仅为独立产品名称、Agent 入口和独立产品不包含的 DSH 宿主外壳。
- 当任一测量或渲染请求重复返回时，页面不得导航抖动、重复创建 iframe、无限增加页数计数或持续触发请求。
